# TrawelWay — Официальный сайт туристического агентства

Готовый многостраничный адаптивный сайт для туристического агентства **TrawelWay**. Проект полностью сверстан, адаптирован под мобильные устройства, планшеты и десктоп, и готов к публикации на GitHub и GitHub Pages.

---

## 📄 3 основные страницы сайта

1. **Главная страница (`Главная`)**
   - Промо-баннер (Hero) с формой быстрого поиска тура (город вылета, страна, даты, количество туристов)
   - Быстрые фильтры по направлениям (Турция 5★, ОАЭ, Египет, Мальдивы, Таиланд, Сочи)
   - Плашка надежности (Единый реестр турагентов РФ №РТА0019482, финансовые гарантии 50 млн ₽ САО «ВСК», рассрочка 0%)
   - Витрина горящих путевок с актуальными ценами, скидками и бейджами
   - Блок официальных партнеров-туроператоров (Anex, Coral Travel, Pegas Touristik, Библио-Глобус, Tez Tour, Fun&Sun)
   - Отзывы туристов с рейтингом
   - Приглашение в офисы продаж и форма заявки

2. **Каталог туров (`Каталог туров`)**
   - Полнофункциональный каталог туров
   - Поиск по названию отеля, курорту или стране
   - Фильтрация:
     - По странам (Турция, ОАЭ, Египет, Таиланд, Мальдивы, Россия)
     - По звездности отеля (4★, 5★ Lux)
     - По типу питания (Ultra All Inclusive, All Inclusive, Завтрак + Ужин, Только завтрак)
   - Сортировка: рекомендуемые, по возрастанию цены, по убыванию цены, по рейтингу туристов
   - Интерактивные карточки туров с подробными характеристиками (прямой перелет, багаж, трансфер, пляжная линия)
   - Кнопки «Подробнее» и «Забронировать» на каждой карточке

3. **О компании и контакты (`О компании`)**
   - Информация об агентстве: 14 лет на рынке, 185 000+ довольных туристов, лицензии
   - Интерактивный селектор офисов (Москва Тверская, Санкт-Петербург Невский, Москва-Сити, Сочи) с расписанием, прямым телефоном и адресом
   - Команда ведущих персональных тревел-экспертов
   - Блок часто задаваемых вопросов (FAQ) с раскрывающимся аккордеоном
   - Форма индивидуального подбора тура и консультации

### 🎁 Интерактивное модальное окно бронирования
На любой странице и с любой карточки тура можно открыть модальное окно:
- Выбор или смена отеля/направления
- Выбор города вылета (Москва, СПб, Казань, Екатеринбург, Сочи)
- Выбор даты вылета и количества туристов (взрослые + дети) с динамическим пересчетом стоимости
- Ввод контактных данных клиента
- Подтверждение заявки с генерацией персонального номера бронирования (`TW-XXXXXX`)

## 📁 Структура проекта

Проект организован по стандартной модульной структуре:

```text
├── css/                  # Таблицы стилей (style.css, Tailwind CSS)
├── js/                   # Скрипты, компоненты и данные сайта
│   ├── components/       # Компоненты верстки
│   │   ├── Header.tsx    # Адаптивная шапка сайта с меню и контактами
│   │   ├── Footer.tsx    # Подвал сайта со ссылками на все разделы
│   │   ├── BookingModal.tsx # Модальное окно бронирования и подбора тура
│   │   └── pages/        # 3 страницы сайта + детальный вид тура
│   │       ├── HomePage.tsx      # Главная страница
│   │       ├── CatalogPage.tsx   # Каталог туров с фильтрами
│   │       ├── AboutPage.tsx     # О компании, офисы, FAQ и контакты
│   │       └── TourDetailPage.tsx # Детальная карточка тура
│   ├── data/             # Данные туров, отелей, отзывов и офисов
│   ├── types.ts          # Типизация TypeScript
│   ├── App.tsx           # Корневой компонент с навигацией по 3 страницам
│   └── main.tsx          # Точка входа приложения
├── assets/               # Статические ресурсы (изображения, иконки)
├── index.html            # Главный HTML-документ
├── package.json          # Зависимости и скрипты
├── tsconfig.json         # Конфигурация TypeScript
└── vite.config.ts        # Конфигурация сборщика Vite
```

## 🚀 Запуск и сборка

### Установка зависимостей
```bash
npm install
```

### Запуск локального сервера разработки
```bash
npm run dev
```
Сайт откроется по адресу `http://localhost:3000` (или `http://localhost:5173`).

### Сборка проекта для продакшена / GitHub
```bash
npm run build
```
Скомпилированные оптимизированные файлы будут сохранены в папку `dist/` со структурой:
- `dist/index.html`
- `dist/css/` — собранные стили
- `dist/js/` — собранные скрипты
- `dist/assets/` — медиафайлы

## 📤 Как закинуть проект на GitHub

1. Инициализируйте Git (если еще не инициализирован):
   ```bash
   git init
   git add .
   git commit -m "Готовый сайт турагентства TrawelWay на 3 страницы"
   ```

2. Создайте новый репозиторий на GitHub (например, `trawelway-website`).

3. Свяжите локальный репозиторий с удаленным и отправьте код:
   ```bash
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/trawelway-website.git
   git push -u origin main
   ```

4. *(Опционально)* Для публикации на **GitHub Pages**:
   - В файле `vite.config.ts` укажите `base: './'`
   - Выполните сборку: `npm run build`
   - Опубликуйте ветку с папкой `dist/` (например, через пакет `gh-pages`: `npx gh-pages -d dist`)
